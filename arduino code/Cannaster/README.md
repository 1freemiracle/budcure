# The Cannaster
## Super convenient way to get nugs to the perfect moisture content for canning
The cannaster uses a combination pressure, humidity, and temperature sensor to monitor the conditions inside the baine marie. A voltage converter converts the 3.3v of the D1 mini to 5v that the L293D chip uses to drive the stepper motors. 
### The Cannaster currently uses a timer to turn on the pump, and also a maximum rh level. So that you can set the pump to come on every 1.5 hours and the rh set at 80%, then the pump will turn on less and less until it only turns on every 1.5 hours. The cannaster also uses wifi to display data about the current drying states (well displaying it is a work in progress, but you can download the data from the sensors).
